# 无硬件阶段验证与小额投资计划：先锁现场，再买硬件

> 日期：2026-11-22 ｜ 适用阶段：只有软件和虚拟/合成数据，真实相机、边缘盒和产线尚未到位
>
> 结论先行：**现在不是“没有硬件所以不能验证”，而是“先验证值不值得买硬件”。正确顺序是：软件证据 → 工厂现场确认 → 小额硬件 → 台架验证 → 单站闭环 → 付费试点。没有现场承诺就买硬件，风险比没有硬件更大。**

## 1. 先纠正一个顺序

很多项目会这样走：

```text
拿到投资 → 买相机和边缘盒 → 再去找工厂 → 发现接口不通/样本不够/没人配合
```

更稳的顺序是：

```text
现有软件证据
  → 找到一个愿意提供工位、样件和 MES 接口的工厂
  → 申请只够买一台相机和一个边缘盒的小钱
  → 台架验证真实图像
  → 单站真实闭环
  → 客户付费试点/规模化
```

原因很简单：**硬件不是最大风险，买错现场才是。** 一台相机和一个边缘盒可以盘点、转卖或留作演示；但如果没有工厂配合、没有样件、没有 MES 接口，这些硬件就只是库存。

## 2. 现在没有硬件，能验证什么

现有软件和虚拟数据不是“没东西可证明”，它已经能证明：

- 图像质量门禁、置信度门禁和人工复核路径；
- 本地推理、模型卡、类别级指标和证据哈希；
- SQLite Outbox、幂等、重试、死信和人工重放；
- 进程重启、断网和 MES 超时后的恢复；
- MES 回执、UA 写回和审计时间线；
- 质量证据包的重建、检索和导出；
- 682/682 自动回归。

这些证明的是：**软件底座和失败处理能力已经存在。**

但还不能证明：

- 真实相机、镜头、光源和工装下的图像质量；
- 真实产品的缺陷分布和类别级精度；
- 客户真实 MES 接口、字段和回执；
- 真实产线的节拍、振动、换型和长期稳定性；
- 客户是否愿意为结果付费。

所以小额投资买的不是“软件是否存在”，而是**把软件放进真实硬件和真实接口条件下的证据**。

## 3. 第一步不是买硬件，是锁定一个现场

在申请硬件预算前，先拿到一个工厂的最低限度确认。没有下面这些，不建议花钱：

| 需要确认 | 最低要求 | 没有会怎样 |
|---|---|---|
| 产品族 | 一个产品族、一个质检工位 | 范围失控，无法验收 |
| 缺陷类型 | 一类主要缺陷，最好有 OK/NG 对照 | 模型无法评估 |
| 样件 | 50～100 件 OK/NG 样件，允许拍照和留档 | 无法做台架验证 |
| MES 接口 | 测试环境、接口文档或字段样例 | 只能继续模拟，无法证明闭环 |
| 现场负责人 | 质量负责人 + IT/MES 联系人 | 出问题没人决策 |
| 现场权限 | 2～3 小时现场访问，允许拍照/录像 | 无法采集真实图像 |
| 验收人 | 明确谁签字确认阶段结果 | 做完也无法进入下一步 |

最理想的是拿到一页《现场验证确认单》，写清工位、样件、接口、联系人和允许的验证范围。它不是正式合同，但能证明现场不是想象出来的。

## 4. 小额投资分三档，不要一次买满

### 方案 A：0.5～1 万元，先租/借后买

- 向相机厂商、集成商或本地设备商借用/租赁一台工业相机和光源；
- 边缘盒可以先用现有电脑或小额购买；
- 用工厂样件做台架拍摄和推理；
- 验证“缺陷是否可见、图像是否稳定、模型是否需要重训”。

适合：还没有确定相机型号，或工厂只愿意先给样件、不愿意让设备进线。

### 方案 B：1～2 万元，最小硬件组合

- 一台入门级工业相机；
- 镜头、光源、支架和线缆；
- 一个边缘算力盒；
- 现场安装和少量耗材。

适合：已经确认工位、样件和 MES 接口，准备做真实台架和单站联调。

### 方案 C：3～5 万元，单站闭环

- 更好的相机/光源/工装；
- 现场安装、MES 沙箱联调和故障演练；
- 只在一个工位，不做整线。

适合：方案 B 已通过，证明图像和推理可行，再追加做真实单站闭环。

> 原则：**先租后买、先借后买、先买一台再扩。** 不买整线、不压库存、不在现场确认前下单。

## 5. 三阶段计划

### 阶段 0：零成本现场确认（约 1 周）

目标：确认这个现场值得买硬件。

交付：

- 一页现场确认单；
- 工位、产品族、缺陷类型和样件清单；
- MES 接口/字段样例；
- 现场联系人和验收人；
- 相机/光源/边缘盒的询价单。

停止条件：没有样件、没有 MES 接口、没有负责人、现场不允许拍照。出现任意一项，不买硬件。

### 阶段 1：台架/离线验证（首笔 1～2 万元，约 1～2 周）

目标：确认真实图像能不能支撑质检。

交付：

- 真实样件采集记录；
- 图像质量门禁通过率；
- 类别级 Precision/Recall 和人工复核比例；
- 真实图像与合成数据的差异说明；
- 是否需要重训/补样本的建议；
- 可复现实验命令和原始图像哈希。

停止条件：缺陷在现有光学条件下不可见、图像质量无法稳定、样本量不足、类别指标无法达到双方约定下限。此时停止，不进入 MES 联调。

### 阶段 2：真实单站闭环（追加 1～3 万元，约 2～4 周）

目标：证明一条真实 NG 能可靠进入 MES 并对账。

交付：

- 一个真实工位、一个 MES 测试接口/沙箱；
- 不少于 300 件或覆盖 3 个班次的测试记录；
- NG 投递成功率、重复业务单数量、MES 回执对账一致率；
- 断网、MES 超时、进程重启和重复消息演练；
- 质量证据包和验收报告。

停止条件：真实 MES 接口无法获得、回执无法对账、重复/丢失无法收敛、现场无法持续配合。此时停止，不追加预算。

### 阶段 3：付费试点/规模化（客户或产业资金）

只有阶段 2 通过后，才谈：

- 客户付费单站试点；
- 多工位复制；
- 年度许可；
- MES/集成商渠道；
- 更大规模融资。

## 6. 什么算“验证通过”

每阶段的目标必须在花钱前写清，以下是建议口径，不是保证值：

| 阶段 | 指标 | 说明 |
|---|---|---|
| 0 | 现场确认单完整 | 工位、样件、MES、联系人、验收人 |
| 1 | 图像质量门禁通过率 | 真实样件在约定光照/工位下可稳定采集 |
| 1 | 类别级 Precision/Recall | 只对约定样件和类别成立，不外推产线 |
| 1 | 人工复核比例 | 低置信度和不合格图像必须转人工 |
| 2 | NG 投递成功率 | 在约定测试集和故障场景内可测量 |
| 2 | 重复业务单数量 | 同一业务键不应重复形成业务结果 |
| 2 | MES 回执对账一致率 | 回执号、业务键和审计时间线可逐笔对应 |
| 2 | 恢复时间 | 断网、超时、重启后的恢复时间可测量 |
| 2 | 证据完整率 | 日志、回执、图像哈希和模型版本可复核 |

必须提前说清：

- 不承诺零漏检、零漏单或 exactly-once；
- 合成数据指标不等于真实图像精度；
- 台架通过不等于产线验收；
- 真实 MES 沙箱不等于客户生产环境；
- 目标值由双方书面确认，未达标就不称为“跑通”。

## 7. 投资结构怎么设计

### 7.1 不建议一开始谈股权

没有真实证据时谈估值，双方都容易拍脑袋。更稳的方式是：

- 可报销验证预算；
- 借款/可转股安排；
- 里程碑拨款；
- 产业孵化/创新券；
- 具体条款由双方财务/法务确认。

第一笔只申请 1～2 万元，达标后再申请追加到 3～5 万元。不要一次给满。

### 7.2 硬件归属和退出

付款前写清：

- 相机、镜头、光源、边缘盒归谁所有；
- 谁保管、谁负责损坏和保险；
- 验证失败后硬件保留、归还还是折价转给工厂；
- 未使用余额如何退回；
- 已发生发票和资产如何交接。

### 7.3 资金只用于验证

- 不用于工资、招待、办公室或无关订阅；
- 不买整线设备，不压库存；
- 不先做后要钱，超范围先报价；
- 每周一页进展 + 发票 + 资产清单；
- 投资人可指定技术/财务联系人共同核对。

## 8. 投资人为什么会同意这笔小钱

不是因为他被“AI 故事”说服，而是因为这笔钱具备五个特征：

1. **软件已经存在**：不是从零开发，硬件只是边际投入；
2. **现场先锁定**：不是先买设备再找客户；
3. **首笔很小**：1～2 万元，失败可停；
4. **硬件是资产**：相机和边缘盒可盘点、可保留、可转用；
5. **结果可核验**：真实样件、真实 MES、原始日志和证据包。

一句话：

> **这不是赌 AI，而是用一笔小钱买一个真实工厂问题的可验证答案。**

## 9. 如果投资人不投，替代路径

不要立刻借钱买硬件。先试这些：

- 找相机/光源厂商借测或租赁；
- 找 MES/自动化集成商借测试环境；
- 用工厂现有相机或手机先做样件可见性预判；
- 先卖 1～3 万元诊断，用诊断费覆盖部分硬件；
- 申请园区孵化、创新券或产业基金的小额验证资金；
- 找一个愿意共同承担硬件的设计伙伴。

如果这些都不成立，说明需求或现场关系还没到买硬件的程度。

## 10. 未来 7 天做什么

1. 列 10 个江西本地目标工厂，优先电子/连接器/PCB、铜加工、陶瓷、汽车零部件、锂电/新能源；
2. 约 3 个质量负责人，只问最近一次质检到 MES 的故障，不先推销；
3. 争取 1 次现场访问，确认一个工位、一类缺陷和 50～100 件样件；
4. 拿到 1 份 MES 接口文档或字段样例；
5. 向 3 家相机/边缘盒供应商询价，形成一页预算；
6. 用现有 `/overview` 和 `/vision` 给投资人做一次现场演示；
7. 只有现场确认单成立后，才申请首笔 1～2 万元。

## 11. 一句话总结

> **先锁定一个愿意让你验证的工位，再申请一笔只够买一台相机和一个边缘盒的小钱；用真实样件和真实 MES 沙盒跑出可复现证据，再谈规模。**
