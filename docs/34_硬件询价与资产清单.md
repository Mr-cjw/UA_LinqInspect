## 4. 采购规则

- [ ] 已取得《现场验证确认单》；
- [ ] 至少取得 2～3 家供应商报价；
- [ ] 优先选择可租、可借、可退的方案；
- [ ] 不在现场确认前下单；
- [ ] 不采购整线设备或长期库存；
- [ ] 超范围需求先报价、再决定，不先做后要钱；
- [ ] 所有发票、序列号、照片和资产编号留档。

## 6. 资产归属与退出

| 情形 | 处理方式 |
|---|---|
| 验证正常完成 | 资产留在项目/公司，继续用于下一阶段 |
| 阶段 1 不达标 | 停止追加；资产保留、归还或按约定折价转给工厂 |
| 阶段 2 不达标 | 停止追加；按约定处理硬件和未使用余额 |
| 工厂终止配合 | 资产撤回；已发生费用按发票结算 |
| 投资人决定停止 | 未使用余额退回；硬件按归属约定处置 |
