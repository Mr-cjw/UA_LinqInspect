# 投资人 BP 叙事：边缘质检网关

> 版本：v0.1 ｜ 日期：2026-11-20
>
> 用途：内部打磨和非正式交流。正式融资材料必须用付费试点、回款和交付人天数据更新，不得把规划写成已完成事实。

## 1. 一句话

我们把工厂质检结果进入 MES 的最后一公里，做成可审计、可恢复、可渠道复制的边缘连接器；视觉检测作为受合同指标约束的可选增值模块。

## 2. 问题

工厂已经有视觉、人工质检、PLC 和 MES，但质量结果经常不能可靠地进入业务系统：

- 人工登记和对账成本高；
- NG 开单遗漏或重复；
- MES 超时、断网或维护造成结果丢失；
- 设备重启后状态不一致；
- MES 回执和质检证据无法逐笔对应；
- 每个项目重复开发接口，难以复制。

## 3. 产品

### 3.1 主航道：质检-MES 可靠连接器

- 标准输入契约，接收人工、第三方视觉或自研视觉结果；
- OPC UA 信息模型和 MES 适配；
- SQLite WAL Outbox；
- 幂等、重试、死信和人工重放；
- 回执校验和 UA 写回；
- `correlationId` 贯穿全链路；
- 本地状态和轻量指标。

### 3.2 增值包：YOLO/ONNX 视觉检测

- 边缘推理；
- 图像质量门禁；
- 模型版本和阈值管理；
- 按约定零件、缺陷和现场条件验收；
- 输出标准化结果给连接器。

视觉模块可以单独销售，也可以与连接器组成整套单工位方案，但合同、验收和责任边界分开。

## 4. 切入点和扩张

首期只做一个工位、一个产品族、一种工单类型和一类 MES 接口。

扩张阶梯：

1. 单工位 → 多工位；
2. 单产线 → 多产线、多工厂；
3. 单一 MES 适配器 → 多行业适配器库；
4. 连接器 → 视觉增值、追溯、后续 OEE/RCA。

## 5. 客户与渠道

### 直接客户

已有 MES、视觉或人工质检、存在跨系统闭环痛点的中小型离散制造工厂。

### 渠道客户

- MES 厂商；
- 系统集成商；
- 视觉设备厂商；
- 工业自动化和边缘设备伙伴。

渠道价值：减少每个项目的接口定制，形成可配置的质检采集和 MES 闭环模块。

## 6. 收入结构

- 付费试点和部署服务；
- 工位年度软件许可；
- OEM/白标授权；
- 年度维保和升级；
- 视觉模型适配和增值许可。

商业模式目标不是一次性项目费，而是项目启动后形成可持续许可和维保收入。

## 7. 现金流设计

- 试点合同设置启动款和里程碑款；
- 正式上线前收取许可费；
- 硬件原则上客户自备或实报实销，避免库存和售后吞没现金流；
- 超出范围的接口、算法和现场改造单独报价；
- 只有付费试点才配置全职交付资源。

## 8. 单位经济模型

投资人更新时至少提供：

- 标准单站实施人天；
- 单站合同金额；
- 软件许可收入占比；
- 交付毛利和软件毛利；
- 售前成本；
- 销售周期；
- 回款周期；
- 转正式率和扩站率；
- 年度维保续费率；
- 客户集中度。

产品化目标：标准单站实施控制在 5～10 人天内，后续客户主要依靠配置和适配器复用。

## 9. 竞争壁垒

- MES 适配器和行业模板；
- 可恢复 Outbox 和故障矩阵；
- 回执对账和审计证据；
- 交付工具和运维手册；
- 与 MES/集成商的渠道关系；
- 真实现场故障样本和长期运行数据。

OPC UA 和 YOLO 技术本身不是壁垒，可靠闭环、交付效率和渠道复制才是。

## 10. 融资门槛

正式融资前目标：

- 2～3 个付费连接器试点；
- 至少来自两个独立客户；
- 至少 1 个完成验收、回款和扩站/转正式意向；
- 有故障恢复和回执对账证据；
- 有客户愿意作为参考案例。

同一个工厂两个工位不构成跨客户可复制证据。

## 11. 风险与控制

### 连接器风险

消息丢失、重复、MES 故障、重启恢复和回执不一致。

控制：事务 Outbox、幂等键、租约、回执状态机、死信重放和故障矩阵。

### 视觉风险

漏检、误检、数据不足、模型漂移和现场条件变化。

控制：采图质量门禁、独立数据集、类别级指标、影子运行、模型版本治理、人工兜底和合同责任上限。

### 联合交付风险

视觉误判和投递失败相互混淆。

控制：两套验收、两套责任边界、统一 `correlationId` 和根因归属流程。

### 商业风险

无边界定制、免费 POC、交付人天过高和客户集中。

控制：付费试点、10 人天标准上限、变更单、适配器复用和客户结构目标。

## 12. 资金用途

建议按以下优先级分配：

1. 连接器产品化和可靠性验证；
2. 付费试点交付和标准化；
3. MES 适配器与渠道合作；
4. 轻量观测和现场运维；
5. 视觉增值模块的有界研发。

视觉研发和现场支持设置资源上限，不能吞噬连接器主线。

## 13. 对外表述禁区

- 不宣称已经完全生产级；
- 不宣称 exactly-once；
- 不宣称任意设备零配置接入；
- 不宣称视觉能力不输同行而没有可复现基准；
- 不把模拟 MES 说成真实 MES 对接；
- 不把合成留出集指标或演示图像质量门禁说成客户现场验收；
- 不用单一总体准确率替代类别级漏检、误检指标。
