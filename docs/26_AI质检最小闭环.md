# AI 质检最小闭环：真实推理、门禁与边界

> 定位：证明“图片 → 图像质量门禁 → 本地模型推理 → 缺陷类别/置信度 → 置信度门禁 → NG 进入质量闭环”这条链路真实可运行。
>
> 不是生产视觉验收。训练/验证图像为程序合成，未接真实相机、客户样本和现场产线。

## 1. 一句话

AI 先检查图片是否可判读，再执行真实推理；只有图像质量合格、且达到置信度阈值的 NG 才能进入 Edge Core、MES 回执与设备解释链路。OK 也必须过置信度门禁，低置信度无论预测成 OK 还是 NG 都转人工复核。

## 2. 现场入口

```bash
cd ~/project_files/UA_LinqInspect
.venv/bin/python scripts/demo_edge_core.py --ui --no-open
```

浏览器打开：

```text
http://127.0.0.1:8899/vision
```

首次推理会在本机训练一个小型神经网络，当前测试环境通常需要十几秒到数十秒，具体取决于机器性能；训练完成后，同一进程内的后续请求使用内存中的参数执行前向推理。首次请求的 `inferenceMs` 包含训练时间，不能当作稳态推理延迟。

页面必须同时展示：

- 输入图像与图片 SHA-256；
- 图像质量门禁状态与指标（分辨率、亮度、对比度、清晰度、过曝/欠曝）；
- 缺陷类别、置信度和五类概率分布；
- 模型版本、模型 SHA-256、数据版本、训练/验证样本数；
- 合成留出集总体准确率、宏平均召回率和类别级 Precision/Recall；
- 推理/门禁处理耗时；
- 自动判定阈值；
- 图像 SHA-256 及其哈希口径；
- 已知限制和人工复核边界。

## 3. 当前链路

```text
内置合成样本 / 上传图片
  → Pillow 解码与预处理
  → 图像质量门禁
      ├─ 不合格：REVIEW，不执行自动分类，不自动放行或开单
      └─ 合格：继续推理
  → 灰度池化 + 边缘池化 + 局部对比度池化
  → 小型 MLP 前向推理
  → OK / SCRATCH / DENT / STAIN / MISSING
  → 置信度门禁
      ├─ 置信度低于阈值：REVIEW，转人工复核，不自动开单或放行
      ├─ 达到阈值的 OK：放行，不生成 MES 工单
      └─ 达到阈值的 NG：进入 Edge Core / MES / 设备上下文
```

当前类别：

| 编码 | 中文 |
|---|---|
| `OK` | 正常 |
| `SCRATCH` | 划痕 |
| `DENT` | 凹坑 |
| `STAIN` | 污渍 |
| `MISSING` | 缺件 |

必须说清：

1. 合成样本类间差异明显，准确率高不代表真实工厂图像容易分；
2. 这是闭集分类器，未知缺陷会被归入最相似的已知类别；
3. 概率未做现场校准，高置信度不等于真实产线正确率；
4. 低置信度无论预测成 OK 还是 NG 都只转人工复核，不自动放行或生成 MES 工单；
5. 没有真实相机、光源、镜头、工装、客户标注和现场验收。

## 4.1 图像质量门禁

当前门禁只拦截明显不可用的输入，避免把空白、模糊或曝光错误的图片交给模型“猜一个类别”。门禁不通过时：

- `decision` 固定为 `REVIEW`；
- `predictedClass` 为 `null`，`probabilities` 为空；
- 不执行分类推理，不自动放行，也不生成 MES 工单。

当前阈值：

| 检查项 | 阈值 | 作用 |
|---|---|---|
| 分辨率 | 宽、高均 ≥ 64 px | 拒绝过小图片 |
| 平均亮度 | 0.08～0.92 | 拒绝接近全黑或全白 |
| 对比度 | ≥ 0.015 | 拒绝平坦、无纹理画面 |
| 清晰度 | ≥ 0.008 | 拒绝严重模糊画面 |
| 过曝/欠曝比例 | 任一 ≤ 0.35 | 拒绝大面积饱和或死黑 |

这些阈值是演示用的保守基线，不是现场采图标准。真实产线必须用相机、镜头、光源、工装和客户样本重新验证；门禁通过也不代表模型判断正确。

## 5. HTTP 接口

### 5.1 页面

```text
GET /vision
```

### 5.2 单张图片分类

```text
POST /api/vision/classify
Content-Type: application/json
```

内置样本：

```json
{"sample": "SCRATCH"}
```

上传图片：

```json
{"imageBase64": "data:image/png;base64,..."}
```

返回包含：

```json
{
  "predictedClass": "SCRATCH",
  "predictedLabel": "划痕",
  "confidence": 0.99,
  "decision": "NG",
  "decisionReason": "...",
  "qualityGate": {
    "status": "PASS",
    "reason": "图像质量门禁通过。",
    "metrics": {},
    "checks": []
  },
  "imageSha256": "原始上传字节的 SHA-256；内置样本为规范化 PNG 的 SHA-256",
  "imageHashScope": "original-upload-bytes | canonical-png-bytes",
  "modelCard": {},
  "inferenceMs": 4.2
}
```

成功分类时，`probabilities` 返回五类概率数组且和为 1；图像质量门禁失败时，`probabilities` 为空数组，`predictedClass` 为 `null`。

### 5.3 NG 进入质量闭环

```text
POST /api/vision/run
Content-Type: application/json
```

请求体与分类接口相同。行为：

- 图像质量门禁不通过：返回 `delivery: null`，提示转人工复核，不执行自动分类；
- 达到阈值的 `OK`：返回 `delivery: null`，不生成 MES 工单；
- `REVIEW`：返回 `delivery: null`，提示转人工复核；
- `NG`：把本次推理得到的缺陷类别、置信度、模型版本、模型哈希、数据版本、图片哈希和哈希口径作为联合场景输入，再执行 Edge Core、MES、设备上下文、OEE 和 RCA。

这不是“页面显示一个 NG，后台另写一个假缺陷”。测试会断言联合交付中的 `defectType`、`defectConfidence`、`imageSha256` 和模型哈希都与本次视觉推理一致，`imageId` 由图片哈希派生。

## 6. 上传限制

- 支持 PNG / JPEG / WebP；
- 图片解码后统一转 RGB；
- 单图原始字节上限 8 MB；
- 单图像素上限 2500 万，避免压缩炸弹；
- 分辨率小于 64×64、空白、严重模糊、过曝或欠曝的图片会进入 `REVIEW`；
- 请求体上限 12 MB；
- 非法 Base64、不支持的格式、无法解析的图片、超过字节或像素限制的请求返回 400；
- 图片仅在本机处理，不上传外部服务。

## 8. 接真实模型的切换点

当前实现是硬件无关的最小闭环。接真实 YOLO / ONNX / TensorRT 时，不改变业务侧合同，只替换视觉实现：

```text
相机采集 → 图像质量检查 → 预处理 → 模型推理 → 后处理
         → 类别/置信度/框 → 业务门禁 → Edge Core
```

建议保留以下输出合同：

| 字段 | 含义 |
|---|---|
| `predictedClass` | 缺陷类别或 `OK` |
| `confidence` | 模型置信度 |
| `probabilities` | 类别概率或可解释分数 |
| `modelVersion` | 模型版本 |
| `modelHash` | 模型制品哈希 |
| `datasetVersion` | 数据集版本 |
| `inferenceMs` | 推理与门禁处理耗时；首次请求包含模型训练时间 |
| `imageSha256` | 输入图像哈希 |
| `decision` | `OK / REVIEW / NG` |

首次请求的 `inferenceMs` 包含模型训练，不是稳态推理 P50/P95；做性能验收时必须先完成模型初始化，再单独测量预热后的推理延迟。

替换时必须重新验证：

- 相机、镜头、光源、工装和采集参数；
- 客户样本与标注一致性；
- 类别级 Precision / Recall；
- 漏检率、误检率和 OK/NG 一致率；
- 未知缺陷和分布外样本策略；
- 置信度校准与分类阈值；
- 采图质量、光源稳定性和图像质量门禁阈值；
- P50/P95 推理延迟和稳定吞吐；
- 模型版本、回滚和影子运行；
- 现场漂移、再训练和验收复跑。

## 9. 不能说的话

- 不说当前已经完成生产视觉验收；
- 不把合成留出集准确率说成客户现场精度；
- 不说未知缺陷零漏检；
- 不把模型置信度直接说成正确概率；
- 不把演示用的图像质量门禁说成现场采图验收；
- 不把页面演示说成客户产线结果；
- 不用一个总体准确率替代类别级指标。
