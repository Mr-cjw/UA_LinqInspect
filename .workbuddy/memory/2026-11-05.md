## 修复「工业FDE边缘集成攻坚组」输入框崩溃 + 更新简介

### 崩溃根因（WorkBuddy 5.5.6 应用层 bug，非专家包问题）
- 报错：`identity.profession?.trim is not a function`，栈在 `ExpertChip → resolveExpertChipAvatar → resolveAvatarFallbackSeed`（app.asar/renderer/lib-chat-ui）
- 原因：自定义专家首次被选中时，内存中的 expertSelection 的 `profession` 仍是 plugin.json 里的 `{en, zh}` 双语对象（自定义专家经 `buildExpertFromCustom` → `toI18n` 得到对象；内置专家由服务端下发已本地化的字符串，故不触发）。ExpertChip 按字符串 `.trim()` → 崩溃
- 团队专家若 selection 带 assistantDisplayName/assistantProfession（字符串）会走 team 分支不崩；首次选中时这些字段未挂 → 走 fallback 分支 → 崩
- **应用 summon 完成后会把扁平化（字符串）的 selection 持久化**（`storage/device/scoped/*/newTaskExpert.json`），重启或重试后从存储恢复 → 稳定不再崩。日志证实 11-01 后无复现
- 应对：用户侧只需在报错时点「重试」或重启应用一次；属产品 bug 可反馈官方
